A repository's model.safetensors is 2.9 GB and its config says 1.4 billion parameters. Which storage format are the weights in, and how do you know?	2.9 GB ÷ 1.4 billion ≈ 2 bytes per parameter: 16-bit. A 32-bit copy would be 5.6 GB.	learnml week-07 week-07-day-1
Name the three checkpoint files you need to run a model, and say what happens if the tokenizer is the wrong one.	Config, weights, tokenizer. A wrong tokenizer produces ids that index the wrong embedding rows: the model reads and writes nonsense, and nothing raises an error.	learnml week-07 week-07-day-1
300 labelled trials, a laptop, no GPU: which route fits, and what does fine-tuning need that the laptop lacks?	Route 2, a tiny model on the frozen hidden states: no weight changes, no GPU. Fine-tuning needs memory for gradients and optimizer state on every weight; the other routes run the model forward only.	learnml week-07 week-07-day-1
A batch of 4 sentences padded to 12 tokens goes through SmolLM2-360M (32 layers, width 960). Give the shape of input_ids, the shape of one hidden state, and how many hidden states come back.	(4, 12); (4, 12, 960); 33, the embedding plus one per layer.	learnml week-07 week-07-day-2
What does AutoModelForCausalLM return that AutoModel does not, what shape is it, and when should you avoid asking for it?	<code>.logits</code>, shaped batch × tokens × vocabulary. Skip it when you only need hidden states; it is often the largest tensor in the run.	learnml week-07 week-07-day-2
The padding error appears and you fix it with the eos token. What new silent problem does right-side padding create, and how do you avoid it?	Position −1 of shorter rows is now a pad token, so reading the last position reads padding. Use the attention mask to find each row's real last token, or average over real tokens only.	learnml week-07 week-07-day-2
SmolLM2-135M, width 576, three classes. How many parameters does the probe train, and how many stay frozen?	576 × 3 + 3 = 1731 trained; about 135 million frozen.	learnml week-07 week-07-day-3
A probe reaches 90 % on layer 12 and 60 % on the embedding. What does this say about where the distinction is computed, and what does it not say?	The blocks between the embedding and layer 12 make it linearly readable, so they compute it. It does not say the model uses it, nor that layer 0 lacks it in a nonlinear form.	learnml week-07 week-07-day-3
Why average over real tokens with the mask instead of reading position −1 of a right-padded batch?	Position −1 of a shorter row is padding. The masked mean builds each example's vector from its own tokens only, so the probe cannot learn sentence length by accident.	learnml week-07 week-07-day-3
A 1.7B model: memory for inference in bf16, and for full fine-tuning with Adam in 32-bit, before activations?	3.4 GB for inference; 27 GB for training, at 16 bytes per parameter. The T4's 15 GB cannot hold the second.	learnml week-07 week-07-day-4
The forward pass ran, then the first backward pass raised out-of-memory. Which memory appeared between the two, and name two knobs that shrink it.	Gradients and Adam's state for every parameter, plus saved activations. Shrink with a smaller batch or shorter sequences, freezing most layers, or training only a small piece.	learnml week-07 week-07-day-4
Why is a fine-tuning learning rate around 2e-5 when nanoGPT trains from scratch with AdamW at 6e-4?	The weights already sit near a good minimum. Large steps would throw away the pretraining; small ones adjust it while keeping what it knows.	learnml week-07 week-07-day-4
Same seed, same code, same data, a different GPU: how closely should the two accuracies agree, and what causes the difference?	Closely, but not bit for bit. The seed pins the random choices, not the arithmetic; GPU kernels sum in different orders, so the last decimals can differ.	learnml week-07 week-07-day-5
A colleague sends 'acc = 0.83, seed 1'. Name four more fields you need before you can repeat the run.	Any four of: model id and revision, layer and pooling, split fraction and example count, learning rate and steps, the git hash, library versions.	learnml week-07 week-07-day-5
What does the git hash pin that the config does not?	The code itself, every line of it, including behaviour no config setting describes and bugs nobody has noticed. The config pins only the settings the code reads.	learnml week-07 week-07-day-5
What does <b>Hugging Face Hub</b> mean?	The public website where trained models, datasets and tokenizers are stored, one git repository each, and downloaded from with one line of code.	learnml week-07 vocab
What does <b>model card</b> mean?	The README of a Hub model repository: what it was trained on, what it is for, its licence, its scores and a copy-paste snippet to run it.	learnml week-07 vocab
What does <b>checkpoint files</b> mean?	The files a Hub repository needs to run a model: a config describing the architecture, a weights file, and the tokenizer. Lose one and the others are useless.	learnml week-07 vocab
What does <b>pretraining</b> mean?	The long, expensive first training of a model on huge general data, done once by someone with a data centre. Everyone else starts from its saved weights.	learnml week-07 vocab
What does <b>fine-tuning</b> mean?	Continuing to train a pretrained model on your own smaller data, usually with a tiny learning rate so what it already knows is adjusted, not erased.	learnml week-07 vocab
What does <b>transfer learning</b> mean?	Using what a model learned on one big task to do a different, smaller task. Pretraining then fine-tuning or probing are its two common forms.	learnml week-07 vocab
What does <b>AutoTokenizer</b> mean?	The Transformers class that reads a Hub repository&#x27;s tokenizer files and returns the matching tokenizer: text in, integer token ids and an attention mask out.	learnml week-07 vocab
What does <b>AutoModel</b> mean?	The Transformers class that reads a repository&#x27;s config, builds the right architecture and loads the weights. The ForCausalLM variant adds the next-token output layer.	learnml week-07 vocab
What does <b>config</b> mean?	The list of settings that decide what a model or a run is: layer count, width, vocabulary size for a model; seed, learning rate, data size for a run.	learnml week-07 vocab
What does <b>hidden state</b> mean?	The vector a model holds for one token after one layer. A transformer returns one per token per layer, shaped batch by tokens by width.	learnml week-07 vocab
What does <b>linear probe</b> mean?	A single linear layer trained on a frozen model&#x27;s hidden states to predict a label. If it works, that layer already holds the distinction in a readable form.	learnml week-07 vocab
What does <b>frozen weights</b> mean?	Weights that receive no gradient and never change during a training run. The model is used as a fixed feature extractor while something small on top learns.	learnml week-07 vocab
What does <b>memory footprint</b> mean?	How many bytes a model needs on the GPU. About two bytes per weight to run in 16-bit; about sixteen per weight to fully fine-tune with Adam, before activations.	learnml week-07 vocab
What does <b>fp16</b> mean?	Number formats using 16 bits per value instead of 32, halving memory. fp16 has few large values and overflows easily; bf16 keeps the 32-bit range with coarser steps.	learnml week-07 vocab
What does <b>reproducibility</b> mean?	Someone else, or you next month, gets the same number from the same code, data and settings. Needs a pinned seed, a saved config and a known code version.	learnml week-07 vocab
What does <b>random seed</b> mean?	The starting number for a random number generator. Same seed, same sequence of random choices: initial weights, data shuffles, sampled tokens.	learnml week-07 vocab
What does <b>run log</b> mean?	One row appended per experiment run: time, code version, config, seed, library versions and the result. A methods section written by the code.	learnml week-07 vocab
What does <b>git hash</b> mean?	The short id of the exact code version a run used, printed by git rev-parse. Pins every line of code the way a seed pins the random choices.	learnml week-07 vocab
