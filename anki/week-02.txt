Name the four fields of a Value and say which of them ordinary arithmetic fills in.	<code>data</code>, <code>grad</code>, <code>_prev</code> (parents) and <code>_op</code>. Arithmetic fills <code>data</code>, <code>_prev</code> and <code>_op</code> when it creates the new node; <code>grad</code> stays 0 until a backward pass.	learnml week-02 week-02-day-1
For y = x * 3 + 1 with x requiring grad, what does y.grad_fn print, and what does next_functions point at?	<code><AddBackward0></code>, the last operation. <code>next_functions</code> holds the parents: a <code>MulBackward0</code> for <code>x * 3</code> and <code>None</code> for the constant 1.	learnml week-02 week-02-day-1
Why does PyTorch rebuild the graph on every forward pass instead of storing it once like a scene hierarchy?	The graph is a record of one particular run. Python control flow can take a different path each time, so PyTorch records the operations that actually executed, then discards the record after backward.	learnml week-02 week-02-day-1
For out = a * b, what does each parent receive from out's _backward, in words?	<code>a</code> receives <code>b.data</code> times <code>out.grad</code>; <code>b</code> receives <code>a.data</code> times <code>out.grad</code>. Each gets the incoming gradient times the other input's value.	learnml week-02 week-02-day-2
Give a topological order for d = a·b, e = d + c, L = e·e, and the order the backward pass runs.	One valid order is <code>a, b, d, c, e, L</code> (<code>c</code> may sit anywhere before <code>e</code>). Backward runs the reverse, <code>L, e, c, d, b, a</code>, so every node's gradient is complete before its <code>_backward</code> runs.	learnml week-02 week-02-day-2
What goes wrong if d._backward runs before e._backward, and how would you notice?	<code>d.grad</code> is still 0, so <code>a</code> and <code>b</code> receive 0 and do not learn. Nothing errors; you notice from parameters that never move, or by checking against a numerical gradient.	learnml week-02 week-02-day-2
y = 3x + x at x = 2: what is dy/dx, and which single character in a micrograd closure makes that come out right?	4: the two paths contribute 3 and 1 and they add. The <code>+=</code> in <code>self.grad += ...</code> does the adding.	learnml week-02 week-02-day-3
You call loss.backward() every step and never zero. Describe a.grad after three steps and what the loss curve does.	<code>a.grad</code> holds the sum of all three gradients, so the update grows every step, like a learning rate that keeps increasing. The loss falls at first, then oscillates and runs away.	learnml week-02 week-02-day-3
After zeroing in modern PyTorch, print(w.grad) shows None instead of zeros. Why, and is it a bug?	<code>zero_grad</code> defaults to <code>set_to_none=True</code>, which frees the memory instead of writing zeros. Not a bug; the next backward creates a fresh gradient.	learnml week-02 week-02-day-3
Why is depth without a bend worth nothing? Show it with \(W_2 W_1\).	\(W_2 (W_1 x) = (W_2 W_1)\, x\): one matrix, so two layers are one linear layer with extra parameters, and only the bend makes depth mean anything.	learnml week-02 week-02-day-4
In one sentence, why can a single neuron not fit XOR?	Its decision boundary is a straight line, and XOR's two 1s sit on one diagonal with the two 0s on the other, so no line separates them.	learnml week-02 week-02-day-4
A 2–4–1 MLP with offsets: count its parameters, layer by layer.	Hidden layer: 4 × 2 weights + 4 offsets = 12. Output neuron: 4 weights + 1 offset = 5. 17 in total.	learnml week-02 week-02-day-4
Write the five lines of the training loop in order and name the two orderings you must never swap.	Forward, loss, zero grads, backward, update. Never backward before zeroing (stale gradients add in), never update before backward (you would step along the previous gradient).	learnml week-02 week-02-day-5
An XOR loss curve sits flat near 0.25 for 80 steps, then drops to 0.01. What was happening during the plateau?	The model was parked at a symmetric half-solution, where the gradient is small. The drop is the hidden units taking different jobs.	learnml week-02 week-02-day-5
Why can you not use the number of wrong answers as the loss?	Its derivative is zero almost everywhere and undefined at the jumps, so gradient descent has no slope to follow. A smooth stand-in such as MSE is the discrete-to-continuous move.	learnml week-02 week-02-day-5
What does <b>Value object</b> mean?	A single number wrapped in a tiny class that also remembers which numbers made it and how. The building block of micrograd; a one-number cousin of a tensor.	learnml week-02 vocab
What does <b>micrograd</b> mean?	Karpathy&#x27;s 100-line autograd engine that works on single numbers. Rebuilding it from memory is this week&#x27;s goal, because PyTorch does the same thing on tensors.	learnml week-02 vocab
What does <b>topological order</b> mean?	A listing of graph nodes where every value comes after everything it was made from. Walked in reverse, each gradient is complete before it is passed on.	learnml week-02 vocab
What does <b>gradient accumulation</b> mean?	Gradients are added into a stored slot, never overwritten. Needed when a value feeds two places; a bug when last step&#x27;s gradient is still in the slot.	learnml week-02 vocab
What does <b>zero_grad</b> mean?	Clearing every stored gradient before a backward pass, so the new gradient is not added on top of the old one. In PyTorch: w.grad.zero_() or the zero_grad() call.	learnml week-02 vocab
What does <b>neuron</b> mean?	The smallest unit of a neural network: a weighted sum of its inputs plus an offset, pushed through a bend such as tanh.	learnml week-02 vocab
What does <b>activation function</b> mean?	The fixed bend applied to a neuron&#x27;s weighted sum, such as tanh or ReLU. It has no parameters; it is what stops a stack of layers collapsing into one.	learnml week-02 vocab
What does <b>nonlinearity</b> mean?	Any step whose output is not a weighted sum of its input, like a bend, a clip or a threshold. Without one, stacked layers are just one bigger linear layer.	learnml week-02 vocab
What does <b>ReLU</b> mean?	The activation function max(0, x): negative inputs become zero, positive inputs pass unchanged. Cheap, and its slope is exactly 0 or 1.	learnml week-02 vocab
What does <b>tanh</b> mean?	The S-shaped activation function that squashes any number into the range minus one to one. Steep near zero, flat far out, so large inputs stop passing gradient.	learnml week-02 vocab
What does <b>MLP</b> mean?	Multi-layer perceptron: linear layers stacked with an activation function between each pair. The plainest neural network, and a component inside far larger models.	learnml week-02 vocab
What does <b>hidden layer</b> mean?	Any layer between the input and the output of a network. Its values are not data and not answers, but learned in-between features.	learnml week-02 vocab
What does <b>XOR</b> mean?	Exclusive-or: true when exactly one of two inputs is on. Four points that no single straight line can split, so no single neuron can learn them.	learnml week-02 vocab
What does <b>training loop</b> mean?	The five steps repeated to train any model: forward pass, loss, zero the gradients, backward pass, update the parameters.	learnml week-02 vocab
What does <b>epoch</b> mean?	One full pass through the training data. With a tiny data set that fits in one step, one epoch is one step of the loop.	learnml week-02 vocab
What does <b>loss curve</b> mean?	The loss plotted against training steps. The first thing anyone looks at: falling means learning, flat means stuck, rising means the step is too big.	learnml week-02 vocab
