What does <b>extension layer</b> mean?	One of the seven ways to add to an agent: skills, plugins, marketplaces, hooks, subagents, MCP servers, rules. Each runs somewhere different and costs something different per turn.	learnml agentic-09 vocab
What does <b>plugin marketplace</b> mean?	A repository or folder whose marketplace.json lists plugins and where to fetch them. Add it once, install by name@marketplace. Its name says who publishes the list, not what plugins do.	learnml agentic-09 vocab
What does <b>allowed-tools</b> mean?	A line in a skill&#x27;s front matter that pre-approves tools for the invoking turn. Read it before running a repository&#x27;s skills: a skill can grant itself broad access.	learnml agentic-09 vocab
What does <b>star history</b> mean?	A repository&#x27;s GitHub stars plotted over time, as drawn by star-history.com. A steady slope means sustained use; a one-week spike means a launch or a viral post.	learnml agentic-09 vocab
What does <b>traction</b> mean?	Evidence that other people keep using a tool: weekly new stars, recent pushes, contributors, issues closed. A filter for candidates, never a reason to install.	learnml agentic-09 vocab
What does <b>worth-it rubric</b> mean?	Six lines scored 0 to 2: habit change, context and usage cost, trust, maintenance, both tools, fit. Adopt at 8 of 12 or more with no zero on trust.	learnml agentic-09 vocab
What does <b>ECC</b> mean?	Everything Claude Code: a bundle of hundreds of skills, agents, rules and hooks for Claude Code and Codex. A pattern library to read; installed whole, it costs context every turn.	learnml agentic-09 vocab
What does <b>Pocock skills</b> mean?	Matt Pocock&#x27;s engineering method pack: interview-driven specs, tickets, TDD, code review, handoff. A Claude Code plugin; Codex installs the same folders with npx skills.	learnml agentic-09 vocab
What does <b>tool radar</b> mean?	Your dated table of tools scored with the worth-it rubric: what each changes, score, install line, risk note, check date. Rows enter at 8 or more, leave at monthly refresh.	learnml agentic-09 vocab
What does <b>marketplace scope</b> mean?	Where an installed plugin is enabled: user (every project on this machine), project (everyone in this repository, committed), or local (you, this repository only).	learnml agentic-09 vocab
What does <b>A/B week</b> mean?	One week with a tool installed, logging the same kind of task with and without it: minutes, usage delta, quality 1 to 5. The numbers decide keep or uninstall.	learnml agentic-09 vocab
What does <b>superpowers</b> mean?	Jesse Vincent&#x27;s method plugin for Claude Code and Codex: brainstorm, plan, test-driven development, one subagent per task. Skill bodies load on demand; one hook runs at session start.	learnml agentic-09 vocab
What does <b>document skills</b> mean?	Anthropic&#x27;s skills for reading and writing DOCX, PDF, PPTX and XLSX files, installed as one plugin from the anthropics/skills marketplace. Labelled demonstration quality.	learnml agentic-09 vocab
What does <b>AgentShield</b> mean?	A scanner shipped inside ECC that audits an agent setup for leaked secrets, loose permissions, hook injection and risky MCP servers. Useful on its own, without the bundle.	learnml agentic-09 vocab
