What does <b>/loop</b> mean?	A Claude Code command that re-runs a prompt on an interval inside the open session. Session-scoped: it stops with the session and expires after seven days.	learnml agentic-05 vocab
What does <b>desktop scheduled task</b> mean?	A prompt the Claude Desktop app starts on a schedule as a fresh session on your own machine. Runs only while the app is open and the computer awake.	learnml agentic-05 vocab
What does <b>cloud routine</b> mean?	A saved Claude Code prompt plus repositories that runs as a cloud session whenever a trigger fires, laptop closed, without permission prompts. Research preview; spends your subscription usage.	learnml agentic-05 vocab
What does <b>trigger</b> mean?	What starts a cloud routine&#x27;s run: a schedule (hourly at most), an HTTP call to the routine&#x27;s own endpoint, or a GitHub event such as a pull request opening.	learnml agentic-05 vocab
What does <b>teleport</b> mean?	Pulling a cloud session, its branch and its conversation into your terminal with claude --teleport. Needs a clean tree, the same repository and the same account.	learnml agentic-05 vocab
What does <b>--cloud</b> mean?	The Claude Code flag that starts a new cloud session for the current repository: claude --cloud &quot;task&quot; clones the GitHub remote at your branch, so push first.	learnml agentic-05 vocab
What does <b>GitHub Code Review action</b> mean?	A review that runs on GitHub when a pull request opens: Anthropic&#x27;s managed Code Review (Team and Enterprise, billed separately) or the claude-code-action review workflow, which can use your subscription.	learnml agentic-05 vocab
