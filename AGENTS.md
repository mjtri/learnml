# LearnML — agent instructions

Personal 12-week ML course + 8-week agentic-workflow track, published with MkDocs Material to GitHub Pages. Self-paced: every week exists; weeks are regenerated on request and reviewed by the owner before commit.

## Commands

- `python build_today.py` — regenerate `docs/index.md`, `docs/glossary.md`, `docs/curriculum.md`, glossary includes. Also regenerates the `nav:` block of `mkdocs.yml`. Run before serving or after editing a glossary shard, a lesson title or `curriculum.md`.
- `python check_lessons.py [--only week-05]` — quality gate (word caps, sections, self-paced wording, visuals, glossary shards/ordering, stamps, CSS rule). Must pass before any commit.
- `python build_anki.py week-01` / `agentic-01` — export Anki cards.
- `python gen_week.py 2` / `python gen_week.py agentic 2` — print a (re)generation prompt for one week; `--agent` prints the fan-out prompt used by worktree subagents (never generates by itself).
- `python gen_refresh.py` — print the monthly prompt that re-verifies stamped product claims in Track B.
- `python track.py done <lesson-id> --rating 1-5 [--note ...]` — log progress. Notes stay local.
- Site: `.venv/Scripts/python -m mkdocs serve` (Windows) then open `/learnml/`; build check: `mkdocs build --strict`.

## Layout

- `docs/week-NN/` Track A lessons (`day-1..5.md`, `build.md`); `docs/agentic-NN/` Track B (`day-1..3.md`, `apply.md`).
- `docs/visuals/wNN-*.html` / `bN-*.html` self-contained interactive visuals, ≤ 60 KB, no network calls, prefixed by week.
- `docs/agentic/playbook.md` (owner's rules, hand-edited) and `docs/agentic/changelog.md` (freshness log).
- `glossary/terms-<week-dir>.jsonl` shards (+ `terms-core.jsonl`) are the source for tap-to-define terms; `glossary/OWNERSHIP.md` says which week defines what. Generated files are listed in `LOOP.md` and must not be hand-edited; the `nav:` block in `mkdocs.yml` is generated by `build_today.py` from disk.
- `notebooks/week-NN.ipynb` Colab build sessions with predict-before-run cells.

## Rules

- Follow `LESSON_FORMAT.md` exactly; it is the contract `check_lessons.py` enforces. Self-paced: lessons say "Lesson N", recaps "Previously:", teasers "Next:"; never days.
- Track B product claims cite official pages with `{ .src data-checked="YYYY-MM-DD" }` after fetching them; third-party claims say "(unverified)".
- Never edit `docs/index.md`, `docs/glossary.md`, `docs/curriculum.md`, `includes/`, `docs/javascripts/glossary-map.js`, `anki/` by hand.
