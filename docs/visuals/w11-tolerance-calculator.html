Tolerance: how far off still counts as the same number

test-set standard error √(p(1−p)/n) band = 2 × max(SE, seed sd) gap (yours − claimed) gap in standard errors
ⓘ Words used here
tolerance
How far a reproduced number may land from the claimed one and still count as the same: two standard errors of the test set, or the seed spread, whichever is larger.
standard error
How much a measured accuracy would wobble if the test set were drawn again: √(p(1−p)/n), with p as a fraction.
seed spread
The standard deviation of the number across runs that differ only in the random seed. The paper's number is one draw from it.
verdict
Inside the band: reproduced. Outside: a real gap that needs an explanation.
