ⓘ Words used here
patch
A square block of pixels cut from the image. With 64-pixel images and 16-pixel patches there are 4 × 4 = 16 of them.
token
One element of the sequence a transformer reads. Here, one patch after flattening and a linear layer (the patch embedding).
attention pairs
Attention compares every token with every other, so the work grows with tokens squared.
position vector
A learned vector added to each token so the model can tell patch 5 from patch 6. Without it, shuffling changes nothing.
