ⓘ Words used here
neuron
tanh(w₁x₁ + w₂x₂ + b): a weighted sum, an offset b, and a bend. Its decision boundary is one straight line.
hidden layer
Neurons between input and output. Each draws its own line; the output neuron combines them.
activation function / bend
tanh here. With "no bend", two stacked layers collapse into one line.
XOR
Output 1 when exactly one input is 1: the points (0,1) and (1,0) are 1, the other two are 0.
