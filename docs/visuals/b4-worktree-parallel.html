ⓘ Words used here
worktree
A separate checkout of the same repository with its own files and branch. Claude Code puts them under .claude/worktrees/.
checkout
The working copy of the files on disk. One shared checkout means every session writes to the same files.
merge conflict
Git refusing to combine two branches that changed the same lines, so you decide. Loud, and both versions are kept.
window paid
Each running session is a full context window sent on every turn; three sessions cost about three times one, whatever the file layout.
