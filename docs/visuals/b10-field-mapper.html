trip.yaml keys onto three forms

Tap a key, then the cell it fills (tap a filled cell to clear it). Red cells have no key: check.py counts them.

ⓘ Words used here
field map
The table from data-file keys to the cell, placeholder or macro each format uses; a gap is a cell nobody fills.
data file
trip.yaml: one key per fact, the only thing you type per run.
label
The text in the cell to the left of a value cell; python-hwpx fills "label > right", so a renamed label breaks the map.
oracle
check.py: opens each output, exits 0 when every mapped cell holds its value and 1 when any is empty.
