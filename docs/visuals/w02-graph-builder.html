ⓘ Words used here
Value object
One number plus its history: the parents that made it and the operation that did.
leaf / root
A leaf has no parents (an input or a weight). The root is the final output, the one you call backward on.
topological order
Nodes listed so every node comes after its parents. Backward walks it in reverse.
gradient
How much the root changes per tiny change of that node's value (orange numbers).
