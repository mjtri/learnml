ⓘ Words used here
control
A run that differs from the full method in exactly one column. Only then can the score gap be attributed to that column.
ablation study
A table of controls: remove or swap one part at a time to see which parts carry the gain.
confounded
Two or more columns differ, so the gap could come from any of them. The pair answers no question.
seed
The number that fixes every random draw in a run. Two rows that differ only in seed measure noise, not an idea.
