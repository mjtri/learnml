ⓘ Words used here
residual stream
The running sum: the embedding x₀ plus every note a block has added. With residual off, each block replaces the stream instead.
block
One transformer block. Here it computes a small fixed function of the current stream and writes the result.
cosine similarity
1 when two vectors point the same way, 0 when unrelated, −1 when opposite. Measures how much of x₀'s direction is left.
