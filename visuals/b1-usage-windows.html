ⓘ Words used here
usage window
A 5-hour block with a fixed allowance. Here: one block = one window, light session = 40 %, heavy = 80 % of a window (Opus); Sonnet counts about a third of that.
weekly cap
The Claude allowance for all seven days across all models. Here it equals about six heavy Opus windows.
usage pool
Separate allowances: Opus and Sonnet inside Claude; ChatGPT/Codex is another pool entirely.
worst window
The single 5-hour block that came closest to its limit this week.
