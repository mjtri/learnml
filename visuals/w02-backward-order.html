ⓘ Words used here
topological order
Nodes listed so every node comes after its parents. The backward pass walks it in reverse: consumers before the values they consume.
local derivative
One box's own sensitivity to its direct input: for d = a × b, nudging a moves d by b.
upstream gradient
The gradient a node has already received from the nodes that use it. Only complete once all of them have run.
_backward
The small function attached to each node that hands each parent local derivative × the node's own gradient.
