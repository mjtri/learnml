ⓘ Words used here
bottleneck
The narrowest point of a network: here a grid of cells, each holding one of a few levels, exactly like a tactor array.
quantization
Rounding each cell's average brightness to the nearest allowed level. Fewer levels, fewer bits, more rounding error.
reconstruction error
Mean squared difference between the input and the image rebuilt from the code alone. Low error does not guarantee the shapes stay distinct.
bits per frame
What the display can carry per update: number of cells times log₂ of the level count. Equal bits is the fair comparison.
