ⓘ Words used here


hook
A command Claude Code or Codex runs itself at a fixed moment, every time; deterministic, unlike an instruction.


matcher
Which tool a PreToolUse or PostToolUse hook applies to, such as Edit|Write. Stop and SessionStart take none.


exit code
The number a script returns. 0 lets the action proceed; 2 blocks it and sends stderr back as the reason.


Stop event
Fires whenever the agent finishes responding. A blocking Stop hook makes it keep working instead.
