ⓘ Words used here


run log
One row appended per experiment run, never overwritten: when, which code, which settings, which seed, which result.


git hash
The short id of the exact code version, from git rev-parse. The dashed fields are the three pins: seed, config, git hash.


revision
The commit of the Hub model repository you loaded. A model id alone can point at updated weights next month.


repeatability score
A rough weight per field for how much a stranger needs it to get your number again. Not a standard; a prompt to think.
