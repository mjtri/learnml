Nine things an agent must never do silently

Tap an item to set what guards it in your setup: nothing, an instruction line, or a hook or check that runs every time. The counters say how many an unattended run could do without a trace.

ⓘ Words used here
hook
A command Claude Code runs itself at a fixed moment, such as before a tool call. Exit code 2 blocks the call every time.
check.py
The oracle script over the run log: fails on missing fields, dirty code, or smoke rows counted as evidence.
instruction line
A rule in AGENTS.md or CLAUDE.md. Read and weighed by the model; not enforced.
CHANGELOG line
The out-loud version of any of the nine: what changed, why, and the run id that shows it.
