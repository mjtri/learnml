Does the subagent pay for itself?

A big tool result read into the main window is re-sent on every later turn. A subagent reads it once in its own window and returns a summary. Sizes are illustrative; cache reads cost less, but the window still fills.

ⓘ Words used here
subagent
A helper agent with its own fresh window that does a bounded job and returns a summary.
context window
Everything the model sees at once; the whole of it is sent again on every turn.
token
The unit usage is counted in; about three-quarters of an English word. k = thousand.
break-even
The number of later turns at which delegating costs the same as reading directly; beyond it, delegating is cheaper.
