    ⓘ Words used here
    four-part prompt
    Goal, Context, Constraints, Done when. OpenAI's recommended default; it maps onto Anthropic's advice to scope the task, point to sources and give a check.
    guess
    A decision the agent makes because the prompt did not. A wrong one costs a correction, and the correction stays in the context for the rest of the session.
    Done when
    The condition the agent can check itself before it stops: a test, a build, a checker script. Without it, "looks done" is the only signal.
