      ⓘ Words used here
      instruction file
      CLAUDE.md, AGENTS.md and what they pull in: loaded at session start, paid for on every turn.
      precedence
      The reading order: broadest first, nearest last. Files are joined, never replaced, so two conflicting lines leave the agent free to follow either.
      size cap
      Codex stops adding AGENTS.md files once their combined size reaches 32 KiB (default). Claude Code has no byte cap; it targets 200 lines per file.
      on demand
      A file below the launch folder, or a rules file with a paths: line, loads only when the agent opens a matching file.
