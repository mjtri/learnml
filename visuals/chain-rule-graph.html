L = (a × b + c)²: forward fills values, backward fills gradients

blue = value (forward) · orange = gradient ∂L/∂· (backward)
ⓘ Words used here
forward pass
Compute values from inputs to output (blue numbers).
backward pass
Walk from the output back to the inputs, computing how sensitive L is to each value (orange numbers).
local derivative
One box's own sensitivity to its direct input, e.g. for d = a × b, nudging a moves d by b.
chain rule
gradient of my input = local derivative × gradient of my output.
