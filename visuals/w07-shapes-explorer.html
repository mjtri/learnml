ⓘ Words used here


input_ids / attention_mask
What the tokenizer returns: integer token ids, batch by tokens, and a 1/0 mask marking real tokens versus padding.


hidden state
The vector for one token after one layer: batch by tokens by width. A model with L layers returns L + 1 of them, the embedding first.


logits
One score per vocabulary entry per position, batch by tokens by vocabulary. Only the ForCausalLM class returns them.


config
The numbers in config.json that fix every shape: layers L, width d, vocabulary V, plus the MLP width and the number of key/value heads.
