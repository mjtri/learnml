Seven layers, three questions

Tap a layer. The card says what it can do, where it runs and what it costs on every turn; the bars compare the always-on token cost (illustrative sizes).

Always-on tokens per turn, before anything is invoked
ⓘ Words used here
always-on
Text that sits in the context window on every turn whether or not the layer is used: names and descriptions, or a whole instruction file.
outside the sandbox
Code that runs on your machine with your user privileges, not as a tool call the permission rules can stop: hooks, MCP server processes, bin/ executables.
on invoke
The extra cost paid only when the layer is used: a skill body, a subagent's whole second context window, a tool result.
