Read the run's numbers, then name the failure before you reveal it

ⓘ Words used here
train loss / unseen loss
Loss on the rows the model trained on, and on rows it never saw. The gap between them is the first thing to read.
base-text loss
Loss of the model on a fixed plain paragraph, measured before and after fine-tuning. It tracks what the model still remembers.
catastrophic forgetting
The new task overwrote old ability: base-text loss jumps.
data leakage
Test rows reached the training data: unseen loss looks too good, or a few items sit near zero.
memorising
Overfitting a tiny set: train loss keeps falling while unseen loss turns upward.
