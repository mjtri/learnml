A recipe from five parts

Tap a part to remove it and read what a run then does. The sliders below give the payoff for one of your forms.

ⓘ Words used here
data file
The one file you type per run (trip.yaml): one key per fact, kept outside every repository.
template
The form with its cells empty, as the office issued it; replaced whole, never edited.
oracle
A check the agent can run: check.py walks the field map and exits 1 on a key missing from trip.yaml or an empty output cell; fill.py exits 2 on a missing key and writes nothing.
trigger
What starts a run: you typing /trip-forms, or a clock (desktop task, cloud routine).
