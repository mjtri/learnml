ⓘ Words used here
bigram
Predict the next token from the current token only: one row of counts per current token.
probability distribution
A row divided by its sum: every entry at or above 0, and the row adds up to 1.
loss (surprise)
−ln of the probability the model gave to what actually came next. 0 when it was certain; large when it was surprised.
+1 smoothing
Add 1 to every count so nothing has probability 0, since −ln 0 is infinite.
