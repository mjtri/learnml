Five unattended sessions, six harness parts

Tap a part to remove it (tap again to restore) and watch what a five-session run costs. Costs in 5-hour windows are illustrative, not measured.

Usage for the five sessions
ⓘ Words used here
progress file
progress.md: status, next unit, blocked on. Read first, updated last.
CHANGELOG
Units done and failed approaches with why, so no later session retries them.
oracle
A check the agent can run to know it is done: here check.py over the run log.
commit per unit
One git commit per finished unit, after the check passes, so any step rolls back.
