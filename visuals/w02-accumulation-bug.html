ⓘ Words used here
gradient accumulation
Closures add into .grad (+=) so that a value used twice collects both shares. Correct, but it never stops adding.
zero_grad
Setting every .grad back to 0 before a backward pass, so this step's gradient is not stacked on last step's.
closure (_backward)
The small function on each node that hands each parent local derivative × the node's gradient.
loss curve
Loss against step. Falling: learning. Turning upward: the update is too big, here because stale gradients pile up.
