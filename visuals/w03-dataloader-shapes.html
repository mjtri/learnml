ⓘ Words used here
DataLoader
Shuffles the 60,000 examples and hands them out B at a time; the last batch holds whatever is left.
epoch
One full pass over every example. Batches per epoch = 60,000 ÷ B, rounded up.
.grad
The gradient stored on each parameter tensor. Empty until the first backward pass; the optimizer reads it.
parameters
Every learnable number: for a 784→H→10 MLP that is 784·H + H + H·10 + 10.
