Grey hex chips are single bytes that are not a whole character yet (a Korean syllable is three). Ties go to the pair seen first, as in Python's Counter.

ⓘ Words used here
byte
A number 0–255. Text is stored as bytes: one per English letter, three per Korean syllable.
merge rule
One learned step: glue these two tokens into one new token. Applied in learned order.
vocabulary
All tokens the tokenizer can output: 256 bytes plus one per merge.
bytes per token
Compression: how many original bytes an average token now covers.
